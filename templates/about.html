Welcome to ABC Shop!

This is a simple e-commerce application built with Flask and SQLite. It demonstrates basic web development concepts including:

  • User Authentication: Sign up, login, and logout
  • User Profiles: View your information
  • Shopping Cart: Add and remove items from your cart
  • Product : Browse available products
  • Database : SQLite database

Features:

  • Secure password hashing
  • Session management
  • Responsive design
  • Clean and simple interface

This application is perfect for learning web development fundamentals!
